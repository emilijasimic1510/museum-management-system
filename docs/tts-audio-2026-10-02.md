# Lokalni TTS/audio — 2026-10-02

## Implementacija

Produkcija može koristiti Azure Speech provider podešavanjem `MUSEUM_TTS_PROVIDER=azure`. Azure vraća WAV direktno preko HTTPS-a i koristi `MUSEUM_TTS_AZURE_KEY`, `MUSEUM_TTS_AZURE_REGION` i opciono `MUSEUM_TTS_AZURE_VOICE` (podrazumevano `sr-RS-SophieNeural`). Ključevi se ne čuvaju u repozitorijumu. `espeak` ostaje podrazumevani lokalni provider za razvoj; izbor je napravljen Spring konfiguracijom, bez promene API-ja i storage ugovora.

Sistem koristi lokalni **eSpeak NG**, bez cloud naloga, API ključeva ili mrežnog TTS servisa. Izvor je isključivo sačuvani `ExhibitParticipation.contextDescription` (KontekstualniOpis konkretnog UčešćeEksponataNaIzložbi). Globalni opis eksponata se ne koristi. Null, prazan i whitespace opis daju HTTP 400 pre stvaranja fajla.

`TtsService` je zamenljiv/mockable adapter. `EspeakTtsService` poziva executable direktnim `ProcessBuilder` argumentima (`-v sr -b 1 -f <privremeni UTF-8 tekst> -w <privatni WAV>`). Ne koristi shell. Privremeni tekst se briše i postavljen je timeout. Nepostojeći executable ne utiče na startup: samo generisanje vraća HTTP 503 sa jasnom porukom.

Postavka se zaključava u transakciji; sledeća AUDIO verzija za participation + `sr` je maksimum postojećih verzija + 1. Jezik u postojećem modelu je slobodni string, pa `sr` direktno odgovara glasu `sr`. Nove verzije imaju `automaticallyGenerated=true` i vreme sa serverskog Clock-a. Pre upisa proverava se validan WAV. Neuspeh TTS-a ne upisuje sadržaj; pri grešci i rollback-u pokušava se brisanje fajla. Generisani zapisi ne mogu se menjati kroz generički edit endpoint; koristi se nova generacija. Stare verzije ostaju.

DB čuva internu referencu `private-audio:<participation>-sr-v<version>-<UUID>.wav`. API umesto nje vraća prazan `path`; ne otkriva ni ime fajla ni lokalni direktorijum. Download prima samo ID vrednosti. Storage prihvata samo strogo generisani oblik reference i odbija traversal i symlink fajl. Direktorijum se kreira tek pri generisanju. Nema fajlova u `frontend/public`.

## API

- `POST /api/curator/participations/{id}/audio`, telo `{"language":"sr"}`, CURATOR, odgovor 201 sa DigitalContent metadata.
- `GET /api/visits/{visitId}/content/{participationId}/audio/{contentId}`, VISITOR, odgovor `audio/wav`, `Cache-Control: no-store`.

Download prvo poziva postojeći `VisitService.content`: vlasnik aktivne posete, odgovarajuća izložba, dostupna postavka i prethodni scan te postavke tokom te posete. Potom proverava da content ID pripada baš toj postavci i predstavlja privatni AUDIO. Pogrešan content ID daje 404, neskenirano/tuđa poseta 403, završena/istekla poseta 409. CASHIER, GUIDE, MANAGER, VISITOR i sam ADMINISTRATOR nemaju pravo generisanja; potrebna je CURATOR uloga.

Visitor koristi postojeći Angular HttpClient i JWT interceptor za Blob. Player dobija Object URL, koji se oslobađa pri promeni ulaza ili uništavanju komponente. Naknadno dovršeni zahtevi ne stvaraju URL nakon uništavanja. Bira se najveća verzija po jeziku; tekst ostaje vidljiv. Bez audio zapisa prikazuje se neutralna poruka.

## Konfiguracija

| Property | Environment | Podrazumevano |
|---|---|---|
| `museum.tts.espeak-path` | `MUSEUM_TTS_ESPEAK_PATH` | `espeak-ng` |
| `museum.tts.timeout-seconds` | `MUSEUM_TTS_TIMEOUT_SECONDS` | `30` |
| `museum.audio.storage-path` | `MUSEUM_AUDIO_STORAGE_PATH` | `./runtime/audio` |

Relativni storage direktorijum računa se od radnog direktorijuma backend procesa. Ako se aplikacija pokrene iz `backend`, dobija se `backend/runtime/audio`. `runtime/` je gitignored. Za stabilnu lokaciju koristi apsolutnu putanju. Ne biraj javno servirani direktorijum.

Primer lokalnih properties vrednosti (alternativa environment promenljivama):

```properties
museum.tts.espeak-path=C:/Program Files/eSpeak NG/espeak-ng.exe
museum.tts.timeout-seconds=30
museum.audio.storage-path=C:/Users/DELL/Desktop/museum-management-system/museum-management-system/backend/runtime/audio
```

Putanja executable-a iz primera nije hardkodirana u aplikaciji: zameni je stvarnom lokacijom svoje instalacije.

## Windows instalacija i pokretanje

1. Otvori zvanične [eSpeak NG releases](https://github.com/espeak-ng/espeak-ng/releases), preuzmi odgovarajući Windows MSI (x64 za 64-bitni Windows) i pokreni installer. Ovo prati [zvanično Windows uputstvo](https://github.com/espeak-ng/espeak-ng/blob/master/docs/guide.md#windows). Instalacija nije obavljena u ovom zadatku.
2. Pronađi instalirani `espeak-ng.exe`. Primer ispod pretpostavlja `C:\Program Files\eSpeak NG\espeak-ng.exe`; promeni vrednost ako se tvoja instalacija razlikuje.
3. U PowerShell-u pokreni:

```powershell
Set-Location 'C:\Users\DELL\Desktop\museum-management-system\museum-management-system\backend'
$env:MUSEUM_TTS_ESPEAK_PATH = 'C:\Program Files\eSpeak NG\espeak-ng.exe'
$env:MUSEUM_TTS_TIMEOUT_SECONDS = '30'
$env:MUSEUM_AUDIO_STORAGE_PATH = Join-Path (Get-Location) 'runtime\audio'
Test-Path -LiteralPath $env:MUSEUM_TTS_ESPEAK_PATH
& $env:MUSEUM_TTS_ESPEAK_PATH --version
& $env:MUSEUM_TTS_ESPEAK_PATH --voices=sr
# Zadrži postojeći JWT_SECRET. Samo ako nije podešen u ovom terminalu:
if (-not $env:JWT_SECRET) {
  $env:JWT_SECRET = [Convert]::ToBase64String([Security.Cryptography.RandomNumberGenerator]::GetBytes(48))
}
.\mvnw.cmd spring-boot:run '-Dspring-boot.run.profiles=local'
```

Zadrži postojeću konfiguraciju PostgreSQL/Neo4j i lokalnih naloga iz README-a. Novi JWT ključ invalidira ranije tokene, pa se tada ponovo prijavi. Promenljive iz gornjih komandi važe za trenutni terminal i backend koji iz njega pokreneš. Backend treba restartovati nakon podešavanja.

Frontend u drugom terminalu:

```powershell
Set-Location 'C:\Users\DELL\Desktop\museum-management-system\museum-management-system\frontend'
npm start
```

## Demo: Curator tekst → Generate → Visitor scan → Play

Koristi **Jutro na trgu** na izložbi **Grad kroz objektiv**, sa QR tokenom `DEMO-CITY-QR-001`. Numerički participation ID zavisi od postojeće baze; u kustoskom izboru pronađi taj par eksponat/izložba i koristi prikazani ID. Seed je već definisan u projektu; u ovom zadatku nije menjana demo baza.

1. Prijavi se postojećim CURATOR nalogom. Otvori **Postavke**, pronađi navedeno učešće i otvori uređivanje.
2. Unesi ili proveri **kontekstualni opis** baš ove postavke i sačuvaj. Save sam po sebi ne generiše audio.
3. Otvori **Digitalni sadržaj**, izaberi isto učešće. U **Audio vodič** ostavi **Srpski**, klikni **Generiši audio**.
4. Sačekaj uspeh. Proveri jezik `sr`, novu verziju, datum i oznaku automatskog generisanja. Ponovni klik nakon završetka kreira sledeću verziju.
5. Prijavi se kao VISITOR (najlakše drugi browser profil). Kupi ulaznicu za otvoreni termin **Grad kroz objektiv**; CASHIER neka validira njen QR da počne aktivna poseta.
6. U aktivnoj poseti skeniraj QR postavke ili unesi `DEMO-CITY-QR-001` (može i lokalno demo dugme za taj eksponat).
7. Ispod kontekstualnog teksta pojaviće se **Audio vodič**, aktuelna verzija i browser play/pause kontrole. Klikni Play. Alternativno otvori detalje istog eksponata i osveži status skeniranja u dodatnom sadržaju.
8. Pre scan-a audio download mora biti odbijen. Nakon završetka posete novi download je odbijen. Već preuzeti audio se tehnički ne može povući iz browsera.

Ako eSpeak nije instaliran, backend i ostali tokovi rade; **Generiši audio** prikazuje poruku za instalaciju/path. Stari uspešno generisani WAV i dalje se može preuzeti uz važeće Visitor provere. Ako WAV nedostaje, player se ne prikazuje kao pokvaren; tekst ostaje.

## Testiranje i rezultati

Nije potreban pravi eSpeak za automatizovane testove. TTS je mock, a testni WAV se pravi Java audio API-jem. ProcessBuilder je mockovan za non-zero exit, timeout i nedostajući WAV. PostgreSQL integracioni test koristi izolovani Testcontainers kontejner.

Iz korena projekta (Docker mora raditi):

```powershell
$env:JWT_SECRET = [Convert]::ToBase64String([Security.Cryptography.RandomNumberGenerator]::GetBytes(48))
mvn -f backend/pom.xml '-Dtest=AudioServiceTests,AudioIntegrationTests' test
```

Iz `frontend`:

```powershell
npm test -- --include=src/app/shared/audio-guide.spec.ts --include=src/app/shared/visitor-content.spec.ts --include=src/app/pages/curator-audio.spec.ts --include=src/app/pages/curator.spec.ts --include=src/app/pages/visit-lifecycle.spec.ts
npx tsc --noEmit -p tsconfig.app.json
npx tsc --noEmit -p tsconfig.spec.json
```

Iz korena: `git diff --check`.

Rezultati: backend **12/12** prolazi (11 unit + 1 integracioni test sa kompletnim generisanje/scan/download tokovima). Frontend **39/40** prolazi, uključujući svih 6 novih audio testova. Jedini pad je postojeći `curator.spec.ts` test `allows ADMINISTRATOR and shows only management navigation`: očekuje link Postavke, dok sadašnji Admin meni ima administratorske linkove. Admin i taj test nisu menjani. TypeScript app/spec noEmit prolaze. Git diff --check prolazi uz postojeća LF/CRLF upozorenja. Full clean suite nije pokrenut.

## Ograničenja

- Trenutno je podržan samo `sr`. eSpeak glas je sintetički; stvarni izgovor i browser playback sa instaliranim eSpeak-om nisu ručno provereni. Executable nije pronađen na PATH-u ovog okruženja.
- Generisanje je sinhrono i drži zaključavanje postavke do završetka; nema reda poslova. Timeout podrazumevano 30 s. Duži tekst može zahtevati veću vrednost.
- WAV se preuzima u celosti kao Blob; nema HTTP Range streaminga. Već preuzeti bajtovi ne mogu se opozvati po završetku posete.
- Storage je lokalni filesystem: nije predviđen za više backend instanci bez zajedničkog skladišta. Backup baze treba uskladiti sa backup-om audio direktorijuma.
- Pri normalnoj grešci/rollback-u postoji cleanup, ali pad procesa/računara može ostaviti orphan fajl. Nema automatskog periodičnog čišćenja; generičko brisanje metadata zapisa ne briše WAV. Storage održavanje je ručno.
- Player podržava novi privatni TTS WAV tok; ranije ručno upisani AUDIO URL-ovi nisu importovani u privatni storage. Njihove postojeće reference ostaju u prikazu.
- EER, entiteti, PostgreSQL šema i Flyway V1–V3 nisu menjani. Nema commit-a/push-a.
